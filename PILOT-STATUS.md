# EIE — Pilot Status and Limitations

**Status:** live, limited pilot as reported by the project founder; no independent production-readiness certification established in this release.

Current pilot focus includes:

- usability, mode differentiation and consistency across Standard/HPM/EPL;
- provider availability, streaming and new-chat reliability;
- account creation, login sessions and tenant access isolation;
- safe memory proposals, approval, export/erasure and conversation management;
- provider token usage, cost limits and operational controls;
- responsible handling of voice and potentially sensitive emotional content;
- operational logs and bounded security evidence.

**Do not promise** fault-free sign-in, universal response integrity, verified erasure, compliance certification, offline LLM inference or that user-submitted data is inaccessible to all external providers. Each requires its own observed production evidence, privacy disclosures and assurance.

Public documentation must exclude direct links to private admin dashboards, credentials, raw app logs or identifiers tied to pilot participants.
